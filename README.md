# 待时闲暇 · Leisure Time

一个为 **SillyTavern** 打造的"闲暇时光"悬浮小窗扩展。点屏幕边缘的胶囊悬浮球，随时进入一个精致的小窗：翻翻书架、读读小说、玩两把 2048——**书、游戏，都安放在这方拿铁奶油色的小天地里**。

> 轻量 · 纯色扁平 · 本地优先 · 无需联网

---

## ✨ 功能一览

### 📚 列表书架
- **一键导入** TXT / Markdown 小说，自动分章（识别「第X章 / 楔子 / 序章 / 引言 / 尾声 / 卷」等）
- **多选删除**：勾选多本批量清理，管理省心
- **最近阅读排序**：刚读的书自动置顶，未读排后
- 长按 / 点按，从书架直进阅读

### 📖 小说阅读器
- **沉浸式阅读**，切到上一章 / 下一章自动回到该章开头
- **字号调节**、阅读进度自动记忆（重开回到原位）
- 支持 **UTF-8 与 GBK / GB18030** 编码，中文站点小说也能正常显示

### 🎮 2048 小游戏
- 滑动 / 键盘方向键操作，得分 · 最高分 · 撤回一应俱全
- 排行榜存本地，休闲解压

### 🛠 其它贴心设计
- **胶囊悬浮球**：燕麦白 + 银色金属质感，可拖拽记忆位置，日/夜双主题
- **内置运行日志面板**：插件出问题时一键查看/复制，便于排查
- **纯本地**：书籍、进度、游戏分数全部存在浏览器存储，不依赖任何外部服务，打开即用

## 🚀 安装方法

把插件放进 SillyTavern 的扩展目录：

```bash
cd SillyTavern/extensions/
git clone https://github.com/zhaoyichan/SillyTavern-Plugin-Leisure.git leisure-time
```

或到 **Releases** 下载 zip，解压为 `leisure-time` 放入 `extensions/`。

然后**重启 SillyTavern**，屏幕边缘会出现胶囊悬浮球，点击即可使用。

---

## 🎯 使用方法

1. 点**悬浮球** → 打开小窗
2. **首页**：最近阅读横滑书架 + 2048 游戏
3. 点**进入书架** → 全部书籍列表，可多选管理、导入新书
4. 点任意一本书 → 进入阅读器，用底部箭头切章
5. 右下可切换**日 / 夜**主题

## 🎨 设计语言

- **拿铁奶油**暖色系，纯色扁平、无阴影堆积，克制清爽
- 日间 / 夜间双主题（夜间暖深褐，保留品牌调性）
- 全部 UI 由 CSS / SVG 生成，**体积小、任意设备显示一致**

---

## 💾 数据说明

- 书籍内容、阅读进度、游戏最高分、悬浮球位置等**全部存储在本地**（localStorage / chat 数据），不上传、不依赖云。
- 卸载插件后本地数据保留，重装可找回。
